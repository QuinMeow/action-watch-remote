# 0.3 琥珀界面实现

用户选择琥珀方案，并要求模式字号略缩、开始录像按钮增高四分之一。本实现用25sp模式标题，主按钮从70dp设计基线取整至88dp（约+25%），未通过缩小触控区换取排版。沿用页头→模式→GPS→录像顺序。视口高度低于290dp时，录像固定在底部88dp区，上方页头/模式/GPS可滚动；主操作保持完整可见。

- 纯黑背景，琥珀#FFCA7A，深色按钮文字#261800
- 左右18dp安全内边距，系统栏使用WindowInsets
- 设置48dp；模式整块64dp；GPS48dp；录像实际布局高88dp
- 设置、模式、GPS、关于使用可滚动原生页面；Back和屏内返回恢复导航
- 录制计时与模式只在相机状态确认后改变；权限/连接错误仍可见
- Debug默认隐藏；设置→关于连续点击版本7次临时启用，离开应用或关闭Debug时清理
- 图标来自Google官方Material Icons，Apache2许可保留在licenses目录

0.2历史验收不作为0.3界面通过依据。0.3真实Android截图、录像和覆盖结果另见本目录REPORT.md。

静态sRGB颜色对比校验：主按钮文字#261800对#FFCA7A为11.53:1；正文#F7F5F1对#000000为19.29:1；琥珀#FFCA7A对#000000为13.98:1。禁用态降低透明度表示不可操作，颜色不是唯一状态提示。
